# 🎓 Student Result Manager

A simple **Python-based Student Result Manager** that allows users to add student records, view all students, and check pass/fail results through a menu-driven command-line interface.

## 🚀 Features

- ➕ Add new students with marks
- 👀 View all student records
- 📊 Check pass/fail result
- 🖥️ Easy-to-use menu-driven interface
- 📂 Stores data using Python dictionaries

## 🛠️ Technologies Used

- Python 3

## 📁 Project Structure

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Student_Result_Manager.git
```

2. Navigate to the project folder

```bash
cd Student_Result_Manager
```

3. Run the program

```bash
python student_result_manager.py
```
