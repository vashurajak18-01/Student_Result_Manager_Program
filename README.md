# 🎓 Student Result Manager

A simple Python-based Student Result Manager that allows users to add student records, view student details, and check pass/fail results through a menu-driven command-line interface.

## 🚀 Features
- Add students with marks
- View all student records
- Check pass/fail results
- Menu-driven interface

## 🛠️ Tech Stack
- Python 3

## ▶️ Run the Project
```bash
python student_result_manager.py
```
